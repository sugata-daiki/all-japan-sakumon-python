# chapter01
## 目的
　この章では, 以下のことができるようになります. 
- ファイルに数値や文字列を書き込み, 保存する ("ファイル出力"). 
- ファイルを読み込んで, 数値を取り出して利用する ("ファイル入力"). 
- 「パス」を操作することで, 任意の位置にあるファイルに対して出力・入力する. 

## ファイル入力
"simpleInput.py"を参照してください. 
### 内容の説明
```python
import sys
import numpy as np
```
必要なライブラリ (どこかの誰かが作った便利な関数群, と思って差し支えないです) を取り込む処理です. 

```python
if __name__ == '__main__':
    # この後に処理が続く
```
「該当ファイルが`python simpleInput.py`のように直接実行されたときのみ, 以下の処理を実行する」ということを表しています. ライブラリとして取り込まれたとき = 間接的に実行されるときには, 「以下の処理」は実行されません. とはいってもよく分からないと思うので, その場合は「pythonのプログラムを実行するときのちょっとしたおまじない」と思ってもらって差支えありません. 

```python
arr = np.loadtxt("test.txt", dtype=int)
```
`test.txt`には整数が配列の形で書かれています. そこで, 整数としてその配列の書かれたファイルを読み込んでいます. 

```python
print(arr)
```
arrの中身を標準出力 (画面に表示) します. 

```python
sys.exit(0)
```
プログラムが正常に終了したことを明示的に示します.
